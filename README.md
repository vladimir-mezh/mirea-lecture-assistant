# MIREA Lecture Assistant

Кроссплатформенное desktop-приложение для расписания онлайн-пар и поиска QR-кодов
посещаемости. Основная платформа — Windows; тот же код запускается на macOS и Linux.

## Что уже работает

- автоматический вход через MIREA SSO: пароль хранится в системном защищённом хранилище,
  а свежий 2FA-код автоматически читается по защищённому IMAP из Gmail, Яндекса,
  Mail.ru или совместимого аккаунта Microsoft; доступен и ручной сервер для другой почты;
- проверка входа различает истёкшую сессию и недоступную сеть: при обрыве интернета
  рабочая сессия не удаляется, а вход и получение OTP повторяются с задержкой;
- получение личного расписания из «Пульса» через `pymirea`;
- повторная проверка расписания раз в минуту на протяжении пары: поздно появившаяся
  лекция всё равно открывается по правилу предмета `AUTO / ASK / IGNORE`;
- режим `AUTO / ASK / IGNORE` задаётся один раз для всего предмета, а расписание можно
  отфильтровать по любому фактическому типу занятия (`ЛК`, `ПР`, `ДОП` и другим);
- вкладка активной лекции проверяется каждые 10 секунд и открывается заново, если её
  закрыли, браузер завершился или страница сообщила о потере соединения; после трёх
  неудачных восстановлений выделенный браузер перезапускается;
- локальные правила `AUTO / ASK / IGNORE` для предметов;
- привязка ссылки на онлайн-комнату к предмету;
- сканирование экрана (все мониторы) через `mss` + `zxing-cpp`;
- прямой захват вкладки Chrome/Edge, работающий при перекрытом компактном окне;
- интервал сканирования 1–5 секунд (по умолчанию 2 секунды);
- резервное сообщение «Фамилия Имя группа» в чат MTS Link после пяти неудачных
  отправок распознанного QR в MIREA; не более одного сообщения на занятие;
- если за занятие не был распознан ни один QR, резервным сигналом считаются минимум два
  разных сообщения формата «Фамилия Имя группа MIREA» (группа может отличаться от вашей);
  своё сообщение, обычные реплики и нечитаемые QR сами по себе исключаются;
- настраиваемое отключение звука лекции и сворачивание окна после найденного QR;
- проверка домена QR, защита от дублей и история без хранения полного токена;
- строгий авто-фильтр: только MIREA attendance URL с UUID-токеном, прочие QR игнорируются;
- автоматическая отправка валидного QR посещаемости с защитой от повторов;
- текущий QR существует только в памяти: при появлении следующего пятисекундного кода
  предыдущий немедленно снимается с повторной отправки;
- лекция продолжает контролироваться после времени окончания пары, пока MTS Link не
  покажет фактическое завершение (предохранительный предел — два часа после расписания);
- строка последнего сканирования: «Только что», «5 минут назад», «час назад»,
  «вчера», «позавчера» или дата;
- SQLite, системное хранилище секретов и ротация логов.
- безопасный heartbeat захвата раз в 30 секунд: журнал подтверждает работу сканера,
  не сохраняя изображение или текст лекции.

## Запуск

```powershell
py -3.12 -m venv .venv
.venv\Scripts\Activate.ps1
python -m pip install -e ".[dev,build]"
python -m mirea_lecture_assistant
```

На macOS/Linux активация окружения: `source .venv/bin/activate`.

Проверка:

```powershell
pytest
```

Windows-сборка:

```powershell
powershell -ExecutionPolicy Bypass -File ./scripts/build.ps1
```

Результат: `dist/MireaLectureAssistant.exe`. На macOS/Linux выполните
`pyinstaller --clean --noconfirm MireaLectureAssistant.spec` на целевой системе.

## Как пользоваться

1. **Вход.** «Войти в MIREA» на странице «Расписание». При включённом автоматическом
   входе сохранённые в системном хранилище данные используются при каждом запуске, код
   2FA читается из настроенной почты сам, а истёкшая во время работы сессия восстанавливается.
   Слева внизу должно быть «● MIREA: выполнен вход».
2. **Ссылка на комнату.** Расписание «Пульса» ссылку на онлайн-занятие не отдаёт, поэтому
   её нужно один раз вставить в столбец «Ссылка» и нажать Enter. Ссылка сохраняется по
   названию предмета и подставляется во все будущие пары этого предмета.
3. **Режим предмета.** `ASK` (по умолчанию) — приложение спросит перед открытием;
   `AUTO` — откроет само; `IGNORE` — не тронет. Режим тоже привязан к предмету.
4. **Открытие пары.** Раз в минуту проверяется расписание. Пара с заполненной ссылкой
   открывается за N минут до начала (настройка «Подготовиться до пары») и остаётся
   доступной до её конца — поздно появившаяся лекция подхватится. Кнопка «Открыть» в
   строке делает то же вручную.
5. **Браузер.** Лекция открывается в отдельном профиле Chrome/Edge
   (`browser-profile` в каталоге данных). В первый раз в нём нужно войти в MTS Link —
   cookies обычного браузера сюда не переносятся.
6. **Сканирование.** Стартует автоматически сразу после открытия лекции. Вручную —
   кнопка на странице «QR-сканер» или пункт меню в трее. При включённом прямом захвате
   анализируется вкладка запущенного приложением браузера, даже если окно свёрнуто;
   если этот браузер не запущен, сканируются все мониторы.
7. **Отметка.** Валидный QR отправляется автоматически, без подтверждения. Результат
   виден в уведомлении трея и на странице «История».

Закрытие окна крестиком сворачивает приложение в трей; выход — через меню трея.

## Безопасность

Пароль MIREA и пароль приложения выбранной почты хранятся в системном хранилище секретов
(Windows Credential Manager / macOS Keychain / Secret Service). Сессия MIREA туда не
помещается — Windows ограничивает один секрет 2560 байтами, а сессия содержит access- и
refresh-токен, — поэтому она шифруется и лежит в `session.bin` рядом с базой; ключ
шифрования хранится в том же системном хранилище. Полное содержимое QR и
attendance-token не записываются на диск или в логи: текущий QR удерживается только
в оперативной памяти до его смены. В истории сохраняется лишь SHA-256-отпечаток. Валидный QR автоматически
отправляется в MIREA; повтор одного токена блокируется на 30 минут.

## Ограничения v0.1

Microsoft/Outlook официально требует OAuth2 для IMAP. Автоматическое чтение через
пароль работает только для аккаунтов, где Microsoft разрешает пароль приложения;
иначе приложение предложит ввести полученный код вручную.

Режим `AUTO` открывает найденный адрес комнаты, но не нажимает внутренние кнопки
«Подключиться» конкретной платформы. Для такого шага нужен устойчивый сценарий под её
актуальный интерфейс; открытая вкладка, захват и восстановление уже автоматизированы.
