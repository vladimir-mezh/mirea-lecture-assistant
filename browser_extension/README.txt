Расширение «МИРЭА: пропуск МАКС»

При входе на сайты МИРЭА (Пульс, СДО) после кода иногда появляется страница
«Подтверждение через МАКС» с кнопкой «Пропустить». Расширение нажимает её само.
Работает только на sso.mirea.ru и только когда страница сама предлагает
пропустить. Ничего не читает и никуда не отправляет.

Установка в Chrome, Edge, Яндекс Браузер, Opera, Brave:
1. Откройте страницу расширений: chrome://extensions (в Edge — edge://extensions,
   в Яндексе — browser://extensions).
2. Включите «Режим разработчика».
3. Нажмите «Загрузить распакованное расширение» и выберите эту папку.

Firefox: about:debugging → «Этот Firefox» → «Загрузить временное дополнение» →
manifest.json из этой папки. Firefox забывает такое дополнение после перезапуска.

Папку не удаляйте и не перемещайте: браузер берёт расширение из неё.
