Расширение «МИРЭА: помощник входа»

Когда вы сами входите на сайт МИРЭА (Пульс, СДО), расширение:
- вводит код из письма в поле кода, даже если вкладка неактивна;
- нажимает «Пропустить» на странице «Подтверждение через МАКС», когда страница
  сама это предлагает.

Устанавливается кнопкой в приложении: «Настройки → Вход и почта для кода →
Установить в браузер». Обновляется само вместе с приложением.

Эту папку приложение обновляет и проверяет само, трогать её не нужно. Если её
случайно удалить, приложение вернёт её при следующем запуске.

Расширение работает только на sso.mirea.ru и общается только с приложением на этом
же компьютере (127.0.0.1) по отдельному ключу. Код хранится в памяти не дольше
90 секунд и нигде не записывается. Пароли, чаты и другие поля оно не заполняет.
Не публикуйте файл bridge-config.json: в нём ключ связи с приложением.
