Расширение «МИРЭА: пропуск МАКС и ввод кода» (1.1)

При входе на сайты МИРЭА (Пульс, СДО) после кода иногда появляется страница
«Подтверждение через МАКС» с кнопкой «Пропустить». Расширение нажимает её само.
Работает только на sso.mirea.ru и только когда страница сама предлагает
пропустить. Также вводит почтовый код в поле emailCode, даже в неактивной вкладке.
Связь с приложением: только 127.0.0.1 с отдельным ключом подключения.
Код хранится в памяти до 90 секунд и не записывается в файлы или журналы.
Пароли, чаты и другие формы подтверждения не заполняет.
При нескольких формах входа код остаётся в буфере обмена для ручной вставки.
Без расширения код только копируется; ввод с клавиатуры больше не используется.

Установка в Chrome, Edge, Яндекс Браузер, Opera, Brave:
Сначала подготовьте папку кнопкой расширения в настройках приложения.
Не устанавливайте прямо из исходников: там нет ключа подключения.
1. Откройте страницу расширений: chrome://extensions (в Edge — edge://extensions,
   в Яндексе — browser://extensions).
2. Включите «Режим разработчика».
3. Нажмите «Загрузить распакованное расширение» и выберите эту папку.
4. Если расширение уже установлено, нажмите «Обновить» на его карточке.

Firefox: фоновый ввод кода в этой версии не поддерживается.

Папку не удаляйте и не перемещайте: браузер берёт расширение из неё.
Не публикуйте bridge-config.json: там локальный ключ подключения.
Предупреждения о паролях принадлежат самому Chrome, не сайту. Расширение их
не закрывает. В отдельном профиле приложения сохранение паролей и это
предупреждение отключены; настройки личного браузера приложение не меняет.
Во время получения кода приложение пытается нажать только «Закрыть»/«ОК»
этого предупреждения в окне браузера с МИРЭА, без переключения фокуса.
